# Intrusion Detection System using Machine Learning

## 📌 Project Description
This project is an Intrusion Detection System (IDS) developed using Machine Learning.
It analyzes network traffic data and helps identify whether the network activity is normal or suspicious.

## 🎯 Objective
The main objective of this project is to detect potential network intrusions using machine learning techniques.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Machine Learning Algorithm
- Decision Tree Classifier

## 📂 Project Files
- `ids project.ipynb` - Complete machine learning implementation.

## 📊 Dataset
The dataset used for this project is not included in this repository due to its large file size.
The notebook contains the data preprocessing, analysis, model training and evaluation process.

## 🔍 Project Workflow
1. Data Preprocessing
2. Exploratory Data Analysis
3. Feature Selection
4. Model Training using Decision Tree
5. Prediction
6. Model Evaluation

## 📈 Results
The Decision Tree model was evaluated using suitable performance metrics to detect network intrusions.

## 🚀 How to Run
1. Download or clone this repository.
2. Open `ids project.ipynb` using Jupyter Notebook.
3. Provide the required dataset in the notebook's expected location.
4. Run the notebook cells step by step.
